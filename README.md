# Venue Vue POS

I am building Venue Vue, an offline-first Point of Sale (POS) and event management application.

Please set up the design language and visual layout using Tailwind CSS:

1. Use a clean, modern aesthetic with dark slate primary background/accents, warm gold/amber action highlights, and high contrast for readability in event spaces.

2. Create global typography and smooth transitions for interactive cards and buttons.

3. Build a central application shell layout that includes top header placeholder areas for venue branding, current connection status (Online / Offline mode badge), and quick stats.
